# KI-Werkzeugkasten · Skills und Prompts

Skills und Prompts für den Unterricht der KI Masterclass. Sie sind für Codex gemacht, funktionieren aber mit jedem Werkzeug, das den Agent-Skills-Standard (`SKILL.md`) versteht.

## Skills

| Skill | Was er macht |
|---|---|
| [`seo-geo-sicherheit`](skills/seo-geo-sicherheit/SKILL.md) | Prüft eine Webseite auf SEO, GEO (KI-Suche) und Sicherheit, vergibt Punkte und repariert auf Wunsch |

## Installieren in Codex

Schreib in Codex:

```
Installiere den Skill seo-geo-sicherheit von https://github.com/tonidiba95/ki-werkzeugkasten/tree/main/skills/seo-geo-sicherheit
```

Danach Codex neu starten. Prüfen kannst du es mit: „Welche Skills hast du?“

## Sicherheit

**Lies jeden Skill, bevor du ihn installierst.** Ein Skill ist eine Anleitung für die KI, und dort könnte alles drinstehen. Dieser Skill enthält nur Text, er führt keine Programme aus und lädt nichts herunter.
