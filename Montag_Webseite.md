# Montag · Deine Profi-Webseite: die Prompts

Alle Prompts gibst du in **Codex** ein, im selben Projekt/Ordner. Die Teile in [eckigen Klammern] ersetzt du durch dein eigenes Thema.

## Block 1 · Codex kennenlernen

**1. Ordner aufräumen** (im Übungsordner „Chaos“)
```
Sortiere alle Dateien in diesem Ordner in sinnvolle Unterordner nach Art, zum Beispiel Fotos, Rechnungen, Texte, Tabellen und Sonstiges. Benenne unklare Dateinamen verständlich um. Lösche nichts. Schreib am Ende eine Datei UEBERSICHT.md, in der steht, was du gemacht hast.
```

**2. Webseite Stufe 1 · „normal“** (neuer, leerer Ordner)
```
Baue mir eine Webseite für [mein Thema, z. B. das Café „Bohnenglück“ in Leipzig]. Sie soll diese Bereiche haben: Startbereich mit Überschrift, Über uns, Angebot mit [4 Beispielen und Preisen], Öffnungszeiten und Kontakt. Eine Datei index.html mit CSS, alles auf Deutsch.
```

**3. Verbessern per Satz**
```
Mach die Farben wärmer und prüf, ob die Seite auf dem Handy gut aussieht.
```

## Block 2 · GitHub und die Profi-Stufe

**4. Design-Skill installieren**
```
Installiere den Skill frontend-design von https://github.com/anthropics/skills/tree/main/skills/frontend-design
```
Danach Codex neu starten.

**5. Webseite Stufe 2 · „maximal professionell“**
```
Nutze den Skill frontend-design. Gestalte meine Webseite komplett neu, so dass sie aussieht wie von einer professionellen Agentur. Die Inhalte bleiben gleich. Mach zuerst einen kurzen Design-Plan mit Farben, Schriften und Aufbau und zeig ihn mir. Setz ihn danach um. Die Seite muss auch auf dem Handy perfekt aussehen.
```

## Block 3 · SEO, GEO und Sicherheit

**6. Unseren Prüf-Skill installieren**
```
Installiere den Skill seo-geo-sicherheit von https://github.com/tonidiba95/ki-werkzeugkasten/tree/main/skills/seo-geo-sicherheit
```
Danach Codex neu starten.

**7. Prüfen**
```
Prüfe meine Webseite mit dem Skill seo-geo-sicherheit.
```

**8. Reparieren**
```
Repariere alles.
```

## Block 4 · Online stellen

**9. Weg 1 · Netlify Drop**
```
Mach meine Webseite bereit für Netlify Drop. Alle Dateien, die online gehen sollen, kommen in einen Ordner namens online. Prüfe, dass alle Bilder und Links funktionieren.
```
Danach im Browser **app.netlify.com/drop** öffnen und den Ordner `online` ins Fenster ziehen.

**10. Weg 2 · automatisch mit GitHub**
```
Lade meine Webseite in ein neues öffentliches GitHub-Repository namens meine-webseite hoch und schalte GitHub Pages ein. Sag mir am Ende den Link zur Seite. Wenn du dafür eine Anmeldung brauchst, erklär mir Schritt für Schritt, was ich klicken muss.
```

**11. Eine Änderung automatisch online bringen**
```
Ändere die Hauptüberschrift in „[neue Überschrift]“ und lade die Änderung hoch.
```
